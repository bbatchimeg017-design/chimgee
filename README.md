# Бүртгэлийн вэб хуудас

Овог, нэр, утасны дугаар, имэйл хаяг авч, амжилттай бүртгэлийг төслийн хавтас дахь `Register.xlsx` файлд хадгална.

## Ажиллуулах

1. Python 3.9 ба түүнээс дээш хувилбар суулгана.
2. PowerShell эсвэл Terminal дээр энэ төслийн хавтас руу орно.
3. Сангуудыг суулгана:

   ```powershell
   py -m pip install -r requirements.txt
   ```

4. Вэб хуудсыг эхлүүлнэ:

   ```powershell
   py app.py
   ```

5. Хөтөч дээр `http://127.0.0.1:5000` хаягийг нээнэ.

Эхний амжилттай бүртгэлээр `Register.xlsx` файл автоматаар үүснэ. Дараагийн бүртгэлүүд уг файлд мөрөөр нэмэгдэнэ. Имэйл хаягийн жишээ: `bat@example.com`.
